┌─────────────────────────────────────────────────────────────────────────┐
│                    VOICE CONVERSATION FLOW                               │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│  User speaks "Aaj mujhe bahut akela feel ho raha hai"                   │
│       │                                                                  │
│       ▼                                                                  │
│  📤 Frontend sends audio file to POST /conversation/voice               │
│       │                                                                  │
│       ▼                                                                  │
│  🎯 Backend: conversationController.handleVoiceInput()                  │
│       │                                                                  │
│       ├─► Get user's selected role (e.g., "daughter")                   │
│       ├─► Get user's language mix (e.g., "hi-en")                       │
│       │                                                                  │
│       ▼                                                                  │
│  🎤 speechService.transcribeAudio() → Whisper API                       │
│       │                                                                  │
│       ▼ Returns: "Aaj mujhe bahut akela feel ho raha hai"               │
│       │                                                                  │
│       ▼                                                                  │
│  🧠 memoryService.getMemoryContext()                                    │
│       │                                                                  │
│       ▼ Returns: "User lives in Jaipur, daughter in Mumbai..."          │
│       │                                                                  │
│       ▼                                                                  │
│  🤖 aiService.generateResponse()                                        │
│       │                                                                  │
│       ├─► Build system prompt with daughter personality                 │
│       ├─► Inject memory context                                         │
│       ├─► Send to Claude API                                            │
│       │                                                                  │
│       ▼ Returns: "Mummy main samajh sakti hoon..."                      │
│       │                                                                  │
│       ├─► Detect mood: "lonely"                                         │
│       ├─► Detect crisis: null                                           │
│       │                                                                  │
│       ▼                                                                  │
│  🔊 speechService.synthesizeSpeech() → ElevenLabs API                   │
│       │                                                                  │
│       ▼ Returns: Audio buffer (MP3)                                     │
│       │                                                                  │
│       ▼                                                                  │
│  💾 memoryService.saveConversation()                                    │
│       │                                                                  │
│       ├─► Save to database                                              │
│       ├─► Update memory context                                         │
│       │                                                                  │
│       ▼                                                                  │
│  📥 Return audio + metadata to frontend                                 │
│       │                                                                  │
│       ▼                                                                  │
│  🔊 Frontend plays audio response to user                               │
│                                                                          │
│  Total time: ~8-15 seconds                                              │
│                                                                          │
